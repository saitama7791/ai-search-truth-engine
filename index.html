  1. +Mythllms.txtTechnical

    The file almost no AI crawler actually reads. Publishing one changes nothing measurable.

    What the evidence says

    • 97% of 137,000 published llms.txt files were never fetched by any AI bot; bots requested missing llms.txt files 0 times. source → (2026-06)
    • Across ~300k domains, llms.txt showed no effect on AI citations — removing the feature actually improved the prediction model. source → (2025-11)
    • Google's own AI-search guidance lists llms.txt under myths; no engine documents reading it. source → (2026)
    • Google explicitly states: 'You don't need to create new machine readable files... Google Search ignores them.' June 2026 clarification: llms.txt 'will neither harm nor help your visibility or rankings in Google Search, as Google Search ignores them.' source → (2026-06-15)

    By platform

    No effectChatGPTNo documented use.
    No effectGoogle AIGoogle lists it under myths; June 2026 clarification confirms neither harms nor helps.
    No effectPerplexityNo documented use.
    No effectClaudeNo documented use.
    For industrial sellers: Publish one in ten minutes if it satisfies a checklist. Never pay for it, never expect a citation from it, never let a vendor sell it as a fix.

    Confidence: high · Last verified 2026-11-23

  4. +WorkingOriginal statisticsContent

Platform truth panel

What’s running under each answer engine today: the model, the crawler tokens (and what each one actually controls), and how sources get picked.

ChatGPT

OpenAI

Engine: Live web search inside ChatGPT; retrieval over an index that behaves like Bing's system.

Model now: GPT-6 family - Sol powers most ChatGPT answers (since Oct 7 2026), Astra for Pro/Business tiers; free tier on GPT-5.6 Luna.

How it cites: Cites fewer sources per answer but absorbs what it cites more deeply — definitions, numbers, comparisons and procedures get lifted into the answer text. October 2026: citations per answer dropped ~40% (8.99→5.43), inline links rose sharply (0.18→2.81).

Crawler tokens

GPTBotModel training — controls whether your content shapes future models.
OAI-SearchBotLive search index — controls whether your pages can be retrieved and cited in answers.
ChatGPT-UserOn-demand fetch, fires when a user asks ChatGPT to open your page.
OAI-AdsBotAd landing-page validation; respects robots.txt.

Weakest link to classic authority metrics of all major engines — the most open surface for lesser-known brands. Source mix shifts abruptly: Reddit citation share collapsed 86-94% in Aug 2026. Bing indexing is the practical gateway: pages absent from Bing rarely cited.

Citation vs absorption study (arXiv 2604.25707) Ahrefs 75k-brand correlation study, Dec 2022 OpenAI bots documentation

Google AI Overviews & AI Mode

Google

Engine: Answers grounded in Google Search — the consensus engine.

Model now: Gemini 4 Hydrogen - default in AI Mode globally since 2026-11-12, also used for the hardest AI Overviews questions (replaced Gemini 3.5 Flash).

How it cites: Rewards established brand signal hardest of all engines measured — branded anchors 0.628, branded search volume 0.466. Wikipedia, YouTube, Reddit and .gov sources over-indexed. Inline links substantially increased Oct 15 2026; prominent article carousels for timely content.

Crawler tokens

GooglebotThe search index itself — no Googlebot crawl, no grounding corpus.
Google-ExtendedControls whether Gemini Apps (the assistant) may use your content for grounding and training.
Google-Agent NEWUser-triggered agent fetcher — Google-hosted agents navigate the web and act on user request (search, filter, add-to-cart, booking). Generally ignores robots.txt; allow at CDN/WAF level. Uses user-triggered-agents.json IP ranges, which do not overlap Googlebot's.

AI Mode is the most consensus-driven surface measured: it favors brands the rest of the web already agrees on. Hardest engine for unknown brands; still the one with the most measurable levers. Generative AI performance report in Search Console (since Aug 31 2026) shows impressions for AI Overviews + AI Mode combined.

Ahrefs 75k-brand correlation study, Dec 2022 Ahrefs AI Overview brand-visibility study, May 2025 Google crawler documentation Google crawling docs changelog Allow Google-Agent traffic (Google)

Last verified 2026-11-23

Perplexity

Perplexity AI

Engine: Answer engine with its own crawler and index, plus an agentic browser (Comet).

Model now: Consumer default 'Best' auto-selects per query; paid tiers pick hosted models; the Sonar family continues.

How it cites: Breadth-first citation style with numbered sources; community and technical sources over-indexed; strong grounding discipline — most likely to show the raw source list. ~21.7 citations per answer. 65% of cited pages updated within 1 year.

Crawler tokens

PerplexityBotSurfaces and links websites in Perplexity search results. Not used to crawl content for AI foundation models.
Perplexity-UserFetches a page when a user's question needs it, and links it in the answer. User-requested, so generally ignores robots.txt.

Community and technical sources over-index. The engine most likely to cite a niche industrial blog if it genuinely answers the question. Agent API effort levels (fast, low, medium, high, xhigh, ultra-preview) affect citation format. Computer/Teammates agents for ongoing work.

Claude

Anthropic

Engine: Assistant with a server-side web search tool; leans on curated documentation.

Model now: Claude 5.5 family (Opus/Sonnet/Haiku 5.5); Fable 5.2 for the hardest reasoning since 2026-11-09.

How it cites: Most cautious citation posture of the major engines; prefers curated, documentation-style sources over forum content. ~9.7 citations per answer. Cites Wikipedia in 47.5% of answers. Reddit citations effectively 0%. Three search subprocessors: Brave Search, TurboPuffer, Parallel Web Systems (ShapBot, added Oct 15 2026).

Crawler tokens

ClaudeBotCollects public web content that may contribute to model training.
Claude-UserFetches a page while Claude is answering a user's question — controls whether user-directed search can retrieve your content.
Claude-SearchBot NEWBuilds and refreshes Claude's web-search index — improves search-result relevance and accuracy. Distinct from training (ClaudeBot).

If your content reads like clean documentation — precise names, versions, specs, procedures — Claude retrieves and follows it well. 'No AI training' preference signal now recognized in robots.txt (Oct 30 2026). Blocking ClaudeBot only affects training; blocking Claude-User or Claude-SearchBot reduces search visibility.

Microsoft Copilot

Microsoft

Engine: Bing generative search — answers grounded in the Bing index.

Model now: Consumer Copilot on GPT-5 via Smart router; Bing AI surfaces rebranded to AI Mode / AI Overview in Nov 2026.

How it cites: AI Overview: short sourced summary at top of SERP with source links. AI Mode: conversational answer with inline citation chips and reference list. Citations drawn from Bing index; grounding queries sent to Bing. Bing Webmaster Tools AI Performance report tracks citations (Citation Share, Intents, Topics).

Crawler tokens

bingbotThe Bing index — feeds both classic Bing results and Copilot answers.

Because it rides the Bing index, classic Bing SEO (clean markup, submit via Bing Webmaster Tools) still moves Copilot answers more directly than any 'AI-specific' trick. Two distinct experiences since Nov 2026: AI Mode (conversational) and AI Overview (quick summary). Microsoft recommends IndexNow for freshness. Ads in AI Overviews all markets except China (Nov 19 2026).
